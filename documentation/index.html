Introduction to WhatsOmni

Complete Multi-Tenant B2B Omnichannel SaaS Platform

WhatsOmni is an enterprise-grade multi-tenant B2B conversational operating system that unifies 9 omnichannel messaging & social publishing channels, visual flow automation, AI Copilot & Knowledge Base, Quick Replies canned response studio, Meta Ads (Click-to-WhatsApp/Messenger/IG) lead journeys, an Advanced E-Commerce Suite (Shopify & WooCommerce 2-way product/order sync, interactive WhatsApp catalogs, automated shopping chatbots & 30-min cart recovery), 2 configurable AI operational models (BYOK and Master Fixed with Central Feature Routing), deal CRM pipelines, multi-host calendar booking, multi-currency billing with GeoIP detection, and 7 global payment gateways (Stripe, PayPal, Razorpay, Paystack, Flutterwave, Mercado Pago, and MyFatoorah) into a single command center.

The Unified Operations Architecture

Modern businesses typically juggle 8–12 disconnected software subscriptions: a WhatsApp marketing tool, an Instagram DM manager, a LinkedIn & TikTok social scheduler, a Calendly appointment scheduler, a third-party AI chatbot builder, an e-commerce cart recovery plugin, fragmented regional payment processors, and a standalone CRM like HubSpot or Salesforce.

WhatsOmni unifies every layer of customer communication and automation into a single platform: every customer interaction across 9 channels, AI Copilot drafting, appointment booking, social media post, Meta Ad lead engagement, Quick Reply canned response, e-commerce order inquiry, and cart recovery event connects seamlessly into one real-time contact timeline.

Setup MySQL Database & Redis

Create the MySQL 8.0 relational database schema and verify the in-memory Redis message broker connection.

WhatsOmni relies on MySQL 8.0 (or MariaDB 10.11+) with full utf8mb4 multibyte character support to store multi-tenant records, visual flow graphs, and message transcripts. In-memory Redis is used as the asynchronous queue broker and WebSockets cache store.

Create MySQL Database

Log in to your MySQL terminal client or server CLI and create the dedicated database instance with strict UTF-8 collation:

Terminal 
mysql -u root -p -e "CREATE DATABASE whatsomni_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
Automatic Database Creation in Laravel 12
You can skip manual database creation entirely. When you run php artisan migrate during configuration, Laravel 12 automatically detects if the database does not exist on your MySQL server and prompts: "The database whatsomni_db does not exist on the mysql connection. Would you like to create it? (yes/no)". Simply press Enter (yes) and Laravel will automatically create the database with full utf8mb4_unicode_ci support and execute all migrations for you.

Verify Redis Service Connection

Ensure that the Redis server daemon is running and listening on default port 6379:

Terminal 
redis-cli ping
# Expected response: PONG

Dynamic Admin Panel vs Static .env Configuration
In WhatsOmni, static .env files are strictly reserved for core low-level infrastructure (Database credentials, Redis host, Reverb WebSocket ports, Search Engine daemon, and Worker microservice URL). All third-party integration keys and OAuth client credentials—including Payment Gateways (Stripe, PayPal, Razorpay, Paystack, Flutterwave, Mercado Pago, MyFatoorah), Social & Messaging Channels (Meta, WhatsApp Cloud API, Instagram, Messenger, TikTok, LinkedIn, Telegram, SMS Gateways), CRM & Appointments (Google Sheets/Calendar, HubSpot, Salesforce, Zoho), Video Meetings (Zoom, Microsoft Teams), E-Commerce (Shopify, WooCommerce), Transactional Email (Resend, SMTP), and Central AI Providers (OpenAI, Claude, Gemini, Groq, DeepSeek, xAI, Mistral, OpenRouter)—are configured and managed directly inside the Super Admin Control Panel (stored encrypted with AES-256 in the database). You never need to edit .env files or restart background services when configuring or rotating integration keys!
